# 风资源分析 V0.2：来源、口径与使用

本轮把构想需求 V1 的四类输入与用户提供的标准连接到可执行流程。仅涉及风资源，
不计算光热、财务或整场发电量。**已实现的方法不等于项目整体符合性认证**。

## 使用流程

1. 创建本地项目，在「分析配置 → 数据资料」添加测风塔，分别导入原始、质控、结果及长期参考文件。
2. 点击文件名，确认表头行、数据起始行、分隔符、日期/时间列、时区和步长。
   映射每个通道的要素、统计类型、高度、原单位和支臂，再执行解析。短关键字有边界约束，
   排除词优先；冲突、高度与单位均可手动修改。
3. 在「风资源分析」填写分析年的起点和**排他终点**，例如2024-07-01至2025-07-01。
   明确本次使用的原始/质控/结果文件、温压通道、密度方法、切变层和结果风向，执行计算。
4. 「图表可视化中心」查看同一运行的图与表，筛选通道/月，导出SVG、CSV和完整JSON快照。
   每次运行都有独立标识、输入数据集版本、配置、算法版本和引用快照。
5. 相关性支持同塔、跨塔与长期参考，指定高度对、时段、风向来源、扇区数及回归形式。
   同一高度多个支臂的风速必须明确选择；风向高度存在多个通道时需先消除歧义。
6. 长期参考以结果分析年为周年锚点，计算30/20/10年（可改）窗口及同期值，
   不足指定完整年数不画该均值线。年际图中同期柱为红色。
7. 「审核与处理」提供候选审核、同高双通道取大、总体线性插补、QC切变外推、
   16象限代表年订正和年最大风速极值I型估计。任何处理都产生新序列，不覆盖输入。

## 标准依据与覆盖

2026-11-12查阅官方状态：GB/T18709-2002、GB/T18710-2002、GB/T37523-2019现行，
NB/T31147-2018为现行**能源行业标准**。GB/T18709已有修订计划，不能把修订计划当新标准。
官方链接和核验日期由后端注册表维护，界面「规范库」显示同一份内容。

## 必须区分的口径

- 用户保留率 = QC有效记录 / 同期原始文件记录；标准完整率 = 有效记录 / 应测时间格。
  不以原文件已记录行数替代应测数；未填写计划观测边界时提示无法发现文件两端缺测。
- 10min数据不是小时数据。默认每个完整小时的6个记录都有效才形成小时均值。
  方向用圆周平均；相反方向的零合向量返回缺值；不把小时中尺度复制为6个实测值。
- 风功率密度采用逐条风速立方的平均，禁止用年平均风速的立方代替。
  GB18710 B1的密度为固定期间值；月密度图不暗中替换为逐条动态密度。
- 温压采用同一批有效配对计算年密度；密度所在高度必须核对。
  没有温压时可明确选择海拔估算或有来源的人工密度，不自动填1.225。
- 切变来自实测QC，不从订正、插补或中尺度序列反求；支臂未确认时暂停切变。
  综合切变是同期均值的拟合，不是逐记录切变的平均；负切变可正常报告。
- 企业文件的“标准差的标准差 / 风速”写法与NB31147 5.3.5不同。
  本实现遵循NB公式：先算I，再计算箱内mean(I)、std(I)，特征系数1、代表系数1.28。
- Weibull参数描述拟合，不能证明分布单峰或拟合适用于发电量计算。
- 年最大10min风速、3s极大风速和站点到轮毂的风速不同。
  本轮不把年最大Gumbel结果乘固定1.4作为已审定极大风速，也不以5倍平均值代替专项结果。

## 软件明确约定

标准没有给出全部数值实现细节，以下独立记录，不伪称条款原文：

- 风速分箱采用NB给出的左闭右开中心区间；零箱[0,0.5)，25.5及以上为溢出箱。
- 扇区正北中心，顺时针，左闭右开；统计时360°归北，原始范围审核仍标为边界候选。
- 玫瑰静风默认小于0.5m/s单列，可以选0；百分比分母为同期有效风速风向配对。
- TI跨记录标准差采用样本标准差ddof=1；少于2条不报特征/代表值，少于20条提示。
- 相关性拟合使用全部同期样本，显示散点确定性抽稀到每幅最多1200点；低于30对提示。
- C.1按可调风速组距（默认0.1m/s）建立条件均值点，按参考均值排序后分段线性连接。
  不在曲线范围之外外插；每个参与订正的扇区至少30对；不满足时停止而非套总体回归。
  长期基准含同期，自动实现要求完整小时覆盖；气候相似性及站点一致性需人工确认。
- 极值I型系数默认使用附录D表列样本数；非表列样本数只有在明确选择线性插值后计算。
  本地NB原文n=90时c1=1.20073，未沿用网上某些转录中的错误数值。
- 周年按测风塔日期边界，2月29日移年按2月28日处理，时区明确。
- 原始与QC完整率对照按要素/统计类型/高度/支臂唯一匹配；QC出现原始文件不存在的有效时刻会报错。

## 仍需资料与人工复核

测风塔布设、仪器检定、安装方向、维护及迁站的一致性不能由一份TXT证明。
变更前后的t检验样本还需消除自然风况变化；没有经过构造与确认的样本不自动输出合格结论。
复杂地形流场、气象站向场址的极端风速迁移、标准密度转换和台风专题需要相应资料、
GB51096等后续依据及独立专题计算，本轮没有包装为现成的自动结果。
GB37523附录B.3及C.2–C.4的工程选用、分扇区插补、温压插补、逐月/日内切变外推、
覆冰损失和不确定度评估尚未自动编排；企业的经验快捷法未默认启用。
第二、第五章固定表格与文字描述按负责人后续提供的模板接入，当前预留关联位置。

## 存储、维护与验证

- 后端`core`独立于HTTP与存储，`services`编排，`api`适配，前端按工作区功能拆分。
- 本机开发存储为`data/engine`（可由`AEOLUS_DATA_DIR`指定），PostgreSQL尚未接入。
  `originals/<sha256>.bin`保留字节；`files`来源描述；`datasets`标准化与派生版本；`runs`运行快照。
  写入采用独占创建，原文件读回校验哈希；JSON不允许NaN/Infinity。
- 浏览器保存项目、表单、数据集描述与运行标识，刷新后从本机服务恢复运行。
  不将完整时间序列放进浏览器缓存；配置JSON、结果CSV、运行JSON可分别导出。
- 当前明确支持UTF-8/GB18030文本、UTC/北京时间、每阶段每次一份文件、单文件32MB。
  多段文件合并、数据库迁移、后台大文件任务与报告DOCX生成仍需后续实现。
- 核心测试使用可独立手算的解析数据和确定性分布样本，验证单位、分母、立方平均、
  扇区边界、零风、样本标准差、回归、插补与版本不可变性；不是来自未审定报告的算例抄值。
- 浏览器测试用2024完整年合成数据（52704个10min格、8784小时），验证四类导入、
  映射、真实图表、相关性、周年统计、CSV导出和刷新恢复。合成资料只保存在本地忽略目录。

算法基线见`tests/test_wind_golden.py`。后续变更方法必须保持版本与来源记录；
已通过并确认的工程算法按AGENTS.md要求管理，不悄悄修改公式或边界。
