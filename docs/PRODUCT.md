# 首版范围与验收

负责人于 2026-11-11 授权开始开发。先完成 T0，再逐项交付 T1—T3。
后续首版业务目标：单塔 CSV 导入 → 质量检查 → 基础统计 → 导出归档。
本文记录范围与验收，GitHub Issue / PR 建立后以它们作为任务状态来源。

| 编号 | 范围 | 验收标准 |
|---|---|---|
| T0 | 最小前后端、开发脚本、规范及 CI | 可按 README 安装启动；首页显示实际 API 状态；断连可提示及重试；静态检查、API 测试、前端构建通过 |
| T1 | 工程/塔/传感器/数据集、单塔 CSV 导入、数据库与迁移 | 明确时间及单位；可预览映射；原始文件哈希不变；错误定位行列；全新数据库可迁移；重启可查询 |
| T2 | 缺测、重复、乱序、非法值、范围规则 | 基准数据异常逐项识别；完整率分母明确；原值保留；处理规则可追溯 |
| T3 | 风速统计、月度统计、风向分布、有效率、导出归档 | 结果匹配已确认的基准数据；单位及有效样本数明确；空数据明确提示；成果可重查 |

T0 将数据库接入与业务迁移安排在 T1，一并确定首批真实模型。
T4 再实现数据对齐、相关性和线性回归；T5 在方法与基准确认后实现长期订正。
报告自动生成、AI 校审及商业化 SaaS 属于后续阶段。

## 工程规则确认点

首次数据导入任务必须确认记录时间代表区间起点/终点，以及来源时区、采样间隔和单位。
格式识别不确定时要求显式字段映射，不猜测后静默计算。
质控默认标记异常；删除、替换与插值是显式处理动作，输出独立数据版本。
数据容量验收以实际样本规模确定，不虚报性能指标。
