# 数据契约与首版导入约定

本文定义统一语义。V0.2已实现文本导入和独立版本的本地文件存储，尚无数据库业务表。

| 对象 | 必须记录 |
|---|---|
| 工程 | 唯一 ID、名称；将来加入明确的组织归属 |
| 测风塔 | ID、工程 ID、塔编号、坐标及坐标参考系统 |
| 传感器 | ID、塔 ID、物理量、安装高度（m）、原始单位、统计类型 |
| 数据集 | ID、来源、原始文件哈希、原始文件位置、版本、导入参数 |
| 测量记录 | 传感器、时间、原始值、标准化值、质量标记及规则 ID |
| 分析运行 | 输入数据版本及哈希、规则快照、参数、算法/软件版本、执行时间、结果索引 |

## 时间与缺测

- 同时保留来源时区和原始时间表示；标准化时间必须可无歧义转换到 UTC。
- 明确记录统计区间长度、时间戳表示区间起点还是终点。
- 禁止把缺少时区的时间默认为运行机器的时区。
- 缺测为显式空值及质量标记，不使用 0 代替；无穷值不是有效观测。
- 完整率必须基于明确的分析时间范围、采样间隔和预期记录数；重复记录不能增加有效率。

## 物理量

- 风速：标准单位 m/s，区分瞬时值、区间均值、区间标准差等统计类型。
- 风向：度，明确来源约定并统一为从北顺时针的来向；环向数据使用圆周统计。
- 高度：m，不允许以缺省高度参与风切变计算。
- 温度导入支持℃或K并统一为℃，气压支持Pa/hPa/kPa/mb并统一为Pa；解析前确认映射。

## 首版通道识别范围

2026-11-11，负责人指定以《二章节通道关键字.xlsx》中的规则作为首版范围，后续可以增删。

- 要素：风速、风向、温度、气压、湿度、电压。
- 统计类型：平均值、标准差、最大值、最小值；要素与统计类型分别识别和关联。
- 每项保留关键字、排除关键字及来源。后续通过独立规则配置维护，不将词表写入工程计算公式。
- 具体词表及原始单元格快照留存在本地
  `data/channel-fields/v0.1/`，该目录不进入公开仓库。
- 已接入运行时`backend/src/wind_platform/core/channel_rules.json`，保持独立可维护。
  排除词优先，短字母词按边界识别；自动结果是建议，解析前可修改要素、统计类型、高度、单位和支臂。
  API提供`GET /api/v1/channel-rules`；词表增删修改独立JSON，完整率和计算公式不依赖别名字符串。

## 计算前提

湍流强度需要相同统计区间的风速均值与标准差；风切变需要不同高度的同步有效数据。
缺少输入或适用条件不满足时返回明确原因，不生成正常数值占位。
标准引用应核实版本及适用条件，当前基线不声称符合任何 IEC 计算或认证要求。
